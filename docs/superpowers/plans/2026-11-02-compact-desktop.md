# 桌面紧凑布局 Implementation Plan

> 已按确认原型完成本地实施与验收；用户随后明确授权提交、推送本轮紧凑布局并更新GitHub Pages。独立序号文案修改继续仅保留本地；最终发布状态以Actions与线上验收为准。

**Goal:** 7家样本在1366×768桌面下，四个页签的常用内容控制在1–2屏，录入与评分在同一行对照。

**Architecture:** 沿用评分、规则和工作区模块；桌面表格以样本ID关联实时输入与上次评分快照。重算更新快照，排序不重算；修改输入保留旧结果提示。新增桌面样式文件，手机页面继续使用原有样式和业务流程。

**Tech Stack:** 原生HTML/CSS/JavaScript、Node test、Playwright/Chrome。

## 已确认设计与边界

- 紧凑页头、单行项目栏、四页签；项目管理、规则模板、批量录入和方案恢复按需展开。
- 报价页使用6列可编辑结果表；综合页使用8列可编辑结果表。停用、空报价也保留录入口，未参与结果显示横线。
- 摘要横向排列；详细公式与计算过程折叠；搜索默认折叠，保留全部现有目标、情景、取消和敏感性分析功能。
- 规则配置两列，权重与满分分别成组；样本名称逐行管理，预设折叠。方案保存和比较保持现有快照契约。
- 不修改评分公式、存储格式、历史方案或手机业务逻辑。布局目标针对常规7家样本与默认展开状态；长表和复杂规则允许继续滚动。
